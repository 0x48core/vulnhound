## Initial development (before 0.1.0)

Work merged before releases were automated. Later entries are generated by
[release-please](https://github.com/googleapis/release-please) from
[Conventional Commits](https://www.conventionalcommits.org).

### Features

* `vulnhound scan dir`: catalog Go (`go.mod`) and npm (`package-lock.json` v1–v3) dependencies and match them against OSV.dev
* Merge aliased advisories, score CVSS v3 vectors, and report the version that fixes each vulnerability
* Table and JSON output; `--fail-on` severity threshold with stable exit codes; `--skip-dev`
* Reusable GitHub Action with job summary, JSON report, and `findings`/`report` outputs
* Renovate (Go modules) and Dependabot (GitHub Actions) dependency updates
